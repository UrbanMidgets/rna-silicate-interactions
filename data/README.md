# Curated Thesis Data

This directory contains a curated copy of the RNA nucleotide/silicate calculations. The raw source archive is `/data/Seafile`, which was left untouched during migration.

## How To Navigate

Start with `MANIFEST.tsv` for a complete file index. For the main thesis systems, use `primary_calculations/`, then choose the surface type and nucleotide. Each nucleotide/surface folder keeps its docking provenance beside the selected frames so the path from docking to optimisation is visible.

## Layout

- `primary_calculations/canonical_surface/`: neutral AMP, CMP, GMP, and UMP on the canonical silicate surface.
- `primary_calculations/aluminium_surface/`: neutral AMP, CMP, GMP, and UMP on the aluminium-substituted surface.
- `docking/`: docking inputs/outputs retained with the nucleotide/surface they generated.
- `selected_frames/`: frames selected from docking and then optimised.
- `checks/`: non-primary calculations such as unconstrained tests, R2SCAN checks, MD checks, or accidental reruns.
- `supporting_calculations/`: protonated systems, dimer data, and magnesium docking organized by surface type.
- `reference_structures/`: standalone reference surface calculations.
- `scripts/`: scripts copied from the source archive for provenance.

## Frame Folders

A typical selected frame is organised as follows:

```text
frameXX/
  initial/
  solvated/
  dry/
```

`solvated/` contains the CPCM(water) geometry optimisation. `dry/` contains the subsequent dry optimisation started from the solvated result where available.

## Included Files

Included file types are ORCA inputs/outputs, final and trajectory XYZ files, optimisation metadata, bibliography files, density metadata, CPCM correction files, and small CSV/SVG files for check calculations.

Excluded file types include large restart/scratch/binary files such as `.gbw`, `.densities`, `.tmp`, `.log`, and media/rendering files that are not needed for navigating the thesis dataset. Docking swarm files (`*.all.swarm.xyz`) are excluded by default to keep the GitHub dataset smaller. Restore them with `python3 scripts/migrate_seafile_data.py --include-swarms` if the full docking swarms are needed.

## Manifest Columns

`MANIFEST.tsv` contains `system`, `surface`, `frame`, `state`, `role`, `status`, `source_path`, `repo_path`, `size_bytes`, and `notes`. The `status` column is populated for ORCA `.out` files when normal termination could be detected.

## classifications.csv

Generated by `scripts/generate_classifications.py`, one row per `(system, surface, frame, calc_state)`. Regenerate with:

```bash
python3 scripts/generate_classifications.py
```

Key columns:

| Column | Meaning |
| --- | --- |
| `calc_state` | Calculation stage: `solvated`, `dry`, `r2scan`, `unconstrained`, … |
| `role` | `primary`, `supporting`, `check`, `reference`. **`check` rows are not part of the reported dataset** — they include R2SCAN benchmarks, MD checks and accidental reruns. |
| `orca_status` | `normal` where ORCA termination could be confirmed. Blank or `not_normal` means the final energy comes from an unconverged geometry. |
| `predicted_state` | `Covalently Condensed`, `Surface Anchored`, `Sterically Locked`, `Free`, or `Excluded (Off-Basal)`. |
| `Selection_Pass` | `False` when the pose migrated around the cluster periphery and falls outside the basal-face selection criteria. |
| `Final_Bond_Order` | Mayer bond order at the phosphate O–Si contact. |
| `Final_Linkage_Dist` | Distance of the specific O–Si pair identified by population analysis. This is the quantity reported in thesis Table 4.1. |
| `Final_PhosphateO_SurfaceSi_Dist` | Minimum over *all* phosphate oxygens and *all* surface silicons. Not necessarily the bonded pair. |
| `Final_PO_Siloxane_Ring_Centroid_Dist` | Phosphate oxygen to the centroid of the nearest six-membered siloxane ring. |
| `Final_Basal_Height` | Height of the lowest nucleotide atom above the plane of the framework cations. |
| `Final_Overhang_Fraction` | Fraction of nucleotide atoms laterally beyond the slab footprint. |

### Corrections applied

Three defects were fixed; earlier copies of this file are affected.

1. **`dist_PO_siloxane_COM` did not measure a siloxane ring.** The ring groups were never populated, so the code silently fell back to the centroid of the entire slab and reported 3.8–12.3 Å under a ring-centre label. Six-membered rings are now detected from Si/Al–O connectivity, and the column is renamed `Final_PO_Siloxane_Ring_Centroid_Dist`. Where no ring can be identified the value is `NaN`; there is no fallback.
2. **Aluminium was not treated as a framework cation.** Counting Si neighbours alone made the four oxygens bridging the Al substitution look like terminating hydroxyls, which wrongly excluded two genuine Table 4.1 linkages (10b and 12b).
3. **`state` and `State` differed only by case**, which breaks case-insensitive CSV readers. They are now `calc_state` and `predicted_state`.

Gradient companion outputs (`*_engrad.out`) are now deduplicated against their optimisation run; previously they produced a second row reporting bond order 0 for a structure that is in fact linked.

### Reconciliation with thesis Table 4.1

All thirteen P–O–Si linkages in Table 4.1 are reproduced from the deposited data, each matching the published Mayer bond order to within 0.002 and the published distance to within 0.01 Å. All four structures marked † in Table 4.1 are independently recovered as `Excluded (Off-Basal)` from geometry alone, without reference to the thesis.

The adenosine dinucleotide of §4.7 is also present: the single linkage of conformer 2 (bond order 0.934) and the first of the two bidentate linkages of conformer 1 (0.816).

One known discrepancy:

- **Table 4.1 records structures 2a and 3a 0.02 Å longer than the deposited geometry.** The deposited structures give 1.79 Å and 1.77 Å against 1.81 Å and 1.79 Å in the table. Bond orders match exactly (0.859 and 0.885); the converged `.xyz` agrees with the final trajectory frame; and in both cases the next-nearest phosphate O–Si contact is beyond 3.4 Å, so there is no ambiguity about which pair carries the bond. The reported range of 1.75–1.94 Å is unaffected, being set by structures 11a and 9a.

One further caveat: `amp_protonated/aluminium/frame14` carries an accidental rerun (`calc_state = dry_first_accident`, `role = check`) whose P–O···Si separation is 2.010 Å against the 2.0 Å bonding cutoff. It is classified `Surface Anchored` by a margin of 0.01 Å. Filter on `role != "check"` rather than relying on that margin.
